# 🌾 Digital Market Records

A lightweight web application to help **farmers, shopkeepers, and traders** manage market transactions digitally.  
Built with **FastAPI** (backend) and **PostgreSQL** (database), with **multi-language support** (Telugu 🇮🇳 default, English optional).  

---

## ✨ Features

- 📒 **Sales Records** – Record transactions (customers, items, payments)  
- 🧑‍🤝‍🧑 **Customer Management** – Save and track customer details  
- 🏪 **Shop Management** – Manage multiple shops and owners  
- 📊 **Reports** – Generate daily/weekly/monthly summaries  
- 🌐 **Multi-Language UI** – Telugu (default) & English support  

---

## 🛠️ Tech Stack

- **Backend:** [FastAPI](https://fastapi.tiangolo.com/)  
- **Database:** [PostgreSQL](https://www.postgresql.org/)  
- **ORM:** [SQLAlchemy](https://www.sqlalchemy.org/) / [Tortoise ORM](https://tortoise-orm.readthedocs.io/)  
- **Frontend (Planned):** React / Next.js with i18n support  
- **Auth (Planned):** JWT-based authentication
